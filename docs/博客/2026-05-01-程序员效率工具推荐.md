## 终端 & Shell

### Warp

我一直用 Warp 作为主力终端，功能强大，AI 补全很香。

### zsh + starship

```bash
# 安装 starship
curl -sS https://starship.rs/install.sh | sh

# 在 .zshrc 中启用
eval "$(starship init zsh)"
```

## 编辑器

### VS Code

主力编辑器，插件生态丰富。几个必装的：

- GitLens - Git 可视化
- Error Lens - 错误直接在行内显示
- Vim - 键盘流标配

### Neovim

偶尔用，主要写单文件脚本和配置修改。

## 开发工具

| 工具 | 用途 |
|------|------|
| httpie | 命令行 HTTP 请求，比 curl 好用 |
| bat | cat 的替代品，支持语法高亮 |
| fzf | 模糊搜索文件 |
| jq | JSON 处理 |
| tldr | 命令行帮助，比 man 直观 |

## 其他

- **Rectangle** - macOS 窗口管理
- **Raycast** - 效率启动器，比 Spotlight 快
- **Obsidian** - 笔记软件（就是现在用的这个）
