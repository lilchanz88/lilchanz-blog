## 设计要点

1. **同表同口径**：所有题目用同一套 5 张表，避免学完新表
2. **每题标关联 Q**：做完基础 → 看到终极题就有"似曾相识"感
3. **难度阶梯**：基础 SELECT → JOIN → 窗口函数 → CTE 串联 → 综合实战
4. **举一反三**：每道终极题包含 4-6 个考点，对应 4-6 道基础题
5. **进度反馈**：阶段标签显示通过率，终极题需要先完成"高级阶段"
